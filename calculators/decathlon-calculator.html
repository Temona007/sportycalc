How the Decathlon Calculator Works

Key Features

  • Two-way conversion: Enter results to get points, or enter target points to see required performances
  • All 10 events covered (Day 1 + Day 2)
  • Live scoring – Day 1, Day 2, and total points update as you type
  • Manual timing support for 100m, 400m, and 110m hurdles
  • Uses official World Athletics (IAAF 1984) formulas

Events Included

Day 1

  • 100 metres
  • Long Jump
  • Shot Put
  • High Jump
  • 400 metres

Day 2

  • 110 metres Hurdles
  • Discus Throw
  • Pole Vault
  • Javelin Throw
  • 1500 metres

Units Used

  • Running events: seconds (or m:ss for 1500m)
  • Jumps: centimetres
  • Throws: metres

Manual Timing Adjustments

When using manual timing:

  • 100m and 110m Hurdles: +0.24 seconds
  • 400m: +0.14 seconds

Scoring System

Points are calculated using the official World Athletics formulas.

Example:

  • 10.00s in the 100m = 1096 points
  • 10.55s in the 100m = 963 points

Why Use This Calculator?

  • Instant and accurate scoring
  • Useful for athletes and coaches planning target performances
  • Easy way to track progress across all events
  • Helps identify strengths and weak events
  • Perfect for training and competition preparation
